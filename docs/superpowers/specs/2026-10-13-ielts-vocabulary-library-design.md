# 雅思词汇真经词库设计

## 目标

在不改变现有普通模式和简单模式行为的前提下，将《雅思词汇真经》作为独立的第三套内置词库接入 Luma Words。学习者可以在首页按整套词库或任一 List 做选择题练习；可以在背单词页选择一个 List，并按原书顺序进行中文释义到英文拼写的默写。

## 范围与数据

- 来源是用户提供的 PDF《雅思词汇真经》；共有 22 个 List、3,605 个编号词条。
- 每个条目保留 `list`、`order`、`word`、`ipa`、`meaning`，其中 `list` 为 1 至 22，`order` 为该 List 内的原书编号。
- 不跨 List 去重。即使同一英文词在不同 List 中出现，仍作为各自 List 的独立学习条目，以保持原书的数量和顺序。
- 词库放在独立的静态 JavaScript 数据文件中，以免进一步增大现有的单文件页面；页面启动时读取该全局数据。
- 内置词库版本升级时，以独立的 localStorage 键迁移雅思词库；普通模式、简单模式、学习统计、设置和错题本均不被清空。

## 首页选择题

- 训练模式切换器新增“雅思词汇真经”。
- 选中后显示 List 范围选择器：默认“全部 List”，也可选择 List 1 至 List 22。
- 当前练习池由选定范围内的雅思条目组成；正确答案和三项干扰答案均来自该练习池，且继续避免与上一题重复。
- 首页显示当前词库和 List 范围，以及范围内的词数。若范围不足四个可区分选项，显示现有的不可练习提示。
- 该范围选择只影响首页选择题，不影响普通/简单模式，也不会改变背词页的当前 List。

## 背单词与默写

- 背单词页增加“雅思词汇真经”标签，并将 List 1 至 List 22 作为分类入口。
- 选择一个 List 后，词表按 `order` 从小到大显示；搜索只过滤当前选择范围，不改变数据顺序。
- 默写入口在雅思词库下先选择一个 List；随后按该 List 的原书顺序显示中文释义，要求输入英文单词或短语。
- 拼写比对沿用现有逻辑：忽略大小写、空格和连字符差异；答错时将该条目加入共享错题本，成功或失败后自动进入下一词。
- 完成提示显示选定 List 名称和完成词数，返回后可选择其他 List。

## 其他既有功能

- 单词库管理新增雅思词库入口，支持浏览、搜索、编辑、删除、PDF/JSON 导入及 JSON 导出，并保留条目所属的 List 与顺序元数据。
- 新增或导入的雅思条目默认进入一个可识别的“自定义”范围，不自动插入原书 List 的顺序中；原书 List 的定向练习只使用带有效 List 和 order 的条目。
- 错题本仍保持所有词库共享；雅思词条使用包含 List 和顺序的稳定 ID，避免同一英文单词在不同 List 中互相覆盖。
- 学习统计和设置继续全局共享，沿用当前产品行为。

## 错误处理与兼容性

- 如果静态数据缺失、格式错误、List 不存在或筛选后为空，页面不报错；显示可理解的空状态并保留其他词库可用。
- 读取旧版 localStorage 时，将旧设置中的未知词库值回退到普通模式；雅思范围设置缺失或无效时回退到“全部 List”。
- 导入数据只接受包含英文与中文释义的条目。无效 List/order 元数据的条目可被词库管理查看，但不会污染任何原书 List 的顺序练习。

## 验收标准

1. 静态词库包含 22 个 List、3,605 个条目，且各 List 的条目编号连续并与 PDF 的末项编号一致。
2. 首页可切换至雅思词库，并可仅从一个 List 生成四选一题目。
3. 背词页可展示 22 个 List；选择 List 1 时首项为 `atmosphere`，并按编号递增。
4. 默写 List 1 时依次显示词义，提交正确 `atmosphere` 后前进到 `lithosphere`；答错条目进入共享错题本。
5. 普通模式、简单模式、已有错题和本地学习数据均保持可用。
