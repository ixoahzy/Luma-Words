# Luma Words 英语单词训练

一个简洁的英语单词选择题训练网页。无需安装，打开网站即可使用。

## 在线使用

**访问地址：** https://ixoahzy.github.io/Luma-Words/

建议使用最新版 Chrome、Edge、Safari 或 Firefox 浏览器。

## 主要功能

- **三套题库**
  - 普通模式：7749 个不重复单词
  - 简单模式：2819 个中考核心词汇
  - 雅思词汇真经：22 个 List、3605 个词，保留原书顺序
- **雅思 List 专项训练**
  - 首页可选择全部 List 或任意一个 List，再仅从该范围出题
  - 背单词页可选 List，按原书编号查看单词、音标和中文释义
  - 在背单词页点击“听写”，看中文释义依次输入英文单词
- **分类背单词**
  - 普通模式和简单模式分别整理，互不混用
  - 优先组合近义词，再按共同主题和同类概念排列
  - 每个词依次显示英文、音标和中文含义
  - 支持分类筛选、全文搜索和分批加载
- **三种训练方式**
  - 看中文含义选择英文单词
  - 看英文单词选择中文含义
  - 两种题型混合随机
- **即时答题反馈**
  - 答对后绿色提示
  - 答错后标出错误选项和正确答案
  - 支持手动进入下一题或定时自动跳转
- **学习统计**
  - 记录总题数、正确数和准确率
  - 可设置目标题数并查看完成进度
  - 支持清零统计，重新开始
- **共享错题本**
  - 答错的单词会自动加入错题本
  - 已答对的单词也可以手动收藏
  - 普通模式、简单模式和雅思词汇真经共用同一个错题本
  - 支持搜索、编辑、单独删除和全部清空
- **词库管理**
  - 搜索和查看全部单词
  - 手动添加、编辑或删除单词及中文含义
  - 支持全选、批量编辑、批量删除和清空当前题库
  - 支持 PDF 解析导入及 JSON 导入、导出

## 快速开始

1. 打开在线网站。
2. 在答题区上方选择“普通模式”“简单模式”或“雅思词汇真经”。
3. 选择雅思词汇真经后，可继续选择“全部 List”或一个指定 List。
4. 点击右上角“背单词”，可以按分类、近义词和同类词集中记忆；雅思词库则按原书 List 和编号显示。
5. 点击右上角设置按钮，选择训练方式、目标题数和自动跳转时间。
6. 点击答案开始训练；答错的内容会自动记录到错题本。
7. 使用右上角的“错题本”和“单词库”按钮管理学习内容。

## 数据说明

学习统计、设置、词库修改和错题本都保存在当前浏览器的 `localStorage` 中：

- 刷新或重新打开页面后数据仍会保留。
- 不同浏览器、设备或浏览器账号之间不会自动同步。
- 清除浏览器网站数据后，本地学习记录也会被删除。
- 如需备份自定义词库，可以在单词库中导出 JSON 文件。

## 技术说明

项目为纯前端单页应用，主要使用 HTML、CSS 和原生 JavaScript 开发，PDF 解析使用 pdf.js，不需要服务器或数据库。
