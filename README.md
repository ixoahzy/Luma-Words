# DeskTalk 英语单词训练

一个简洁的英语单词选择题训练网页。无需安装，打开网站即可使用。

## 在线使用

**访问地址：** [DeskTalk 公开学习页](https://ixoahzy.github.io/Luma-Words/)

建议使用最新版 Chrome、Edge、Safari 或 Firefox 浏览器。

公开版可直接使用选择题、分类背单词、雅思 List、默写、词库和错题本，电脑关机不影响访问。AI 聊天和语音由主机 Mac 提供，可通过主机控制台共享。GitHub Pages 不运行模型；学习记录保存在各自浏览器中。

## 主要功能

- **三套题库**
  - 普通模式：7749 个不重复单词
  - 简单模式：2819 个中考核心词汇
  - 雅思词汇真经：22 个 List、3605 个词，保留原书顺序
- **雅思 List 专项训练**
  - 首页可选择全部 List 或任意一个 List，再仅从该范围出题
  - 背单词页可选 List，按原书编号查看单词、音标和中文释义
  - 在背单词页点击“听写”，看中文释义依次输入英文单词
- **分类背单词**
  - 普通模式和简单模式分别整理，互不混用
  - 优先组合近义词，再按共同主题和同类概念排列
  - 每个词依次显示英文、音标和中文含义
  - 支持分类筛选、全文搜索和分批加载
- **三种训练方式**
  - 看中文含义选择英文单词
  - 看英文单词选择中文含义
  - 两种题型混合随机
- **即时答题反馈**
  - 答对后绿色提示
  - 答错后标出错误选项和正确答案
  - 支持手动进入下一题或定时自动跳转
- **学习统计**
  - 记录总题数、正确数和准确率
  - 可设置目标题数并查看完成进度
  - 支持清零统计，重新开始
- **共享错题本**
  - 答错的单词会自动加入错题本
  - 已答对的单词也可以手动收藏
  - 普通模式、简单模式和雅思词汇真经共用同一个错题本
  - 支持搜索、编辑、单独删除和全部清空
- **词库管理**
  - 搜索和查看全部单词
  - 手动添加、编辑或删除单词及中文含义
  - 支持全选、批量编辑、批量删除和清空当前题库
  - 支持 PDF 解析导入及 JSON 导入、导出

## 快速开始

1. 打开在线网站。
2. 在答题区上方选择“普通模式”“简单模式”或“雅思词汇真经”。
3. 选择雅思词汇真经后，可继续选择“全部 List”或一个指定 List。
4. 点击右上角“背单词”，可以按分类、近义词和同类词集中记忆；雅思词库则按原书 List 和编号显示。
5. 点击右上角设置按钮，选择训练方式、目标题数和自动跳转时间。
6. 点击答案开始训练；答错的内容会自动记录到错题本。
7. 使用右上角的“错题本”和“单词库”按钮管理学习内容。

## 数据说明

学习统计、设置、词库修改和错题本都保存在当前浏览器的 `localStorage` 中：

- 刷新或重新打开页面后数据仍会保留。
- 不同浏览器、设备或浏览器账号之间不会自动同步。
- 清除浏览器网站数据后，本地学习记录也会被删除。
- 如需备份自定义词库，可以在单词库中导出 JSON 文件。

## 技术说明

项目为纯前端单页应用，主要使用 HTML、CSS 和原生 JavaScript 开发，PDF 解析使用 pdf.js，不需要服务器或数据库。

## 本地 AI 助手

文字聊天使用现有 Ollama 的 `qwen2.5:latest`，无需安装新的 Python 依赖。分别在两个终端启动：

```sh
/usr/local/bin/ollama serve
```

```sh
python3 server.py
```

打开 http://127.0.0.1:8000，点击右下角「AI 助手」。Enter 发送，Shift + Enter 换行；关闭窗口后保留本页对话，刷新后清空。聊天使用当前对话及相关页面资料，不读取历史学习记录。

AI 会结合当前题目、四个选项的词义配对或当前默写词条回答，无需重复粘贴题目；词库留在本地，仅发送相关词条。可以问「这四个意思分别对应什么词？」或点击「讲解当前题」。未作答时不主动标出正确答案。

切换页面、滚动或打开词库、错题本等弹窗时，会实时更新识别资料；发送问题时再次读取当前屏幕。前台弹窗优先于背景题目。页面变化后会取消过时的手动请求、停止旧朗读，并把未完成的问题保留在输入框中；对话记录仍保留。

主动讲解默认开启，选择题和默写答错后，即使没有打开聊天面板，也会自动生成简短小贴士。窗口关闭时在lion旁显示短提示，不会自动展开大窗口；按“自动朗读”设置播放声音，完整回复仍保存在本页聊天记录。可从桌宠齿轮菜单、聊天面板或提示旁暂停主动讲解；开关保存在当前浏览器。背词页提问时会读取当前屏幕内的词条，随滚动、分类和搜索结果更新，不必先点击单词；「讲解当前屏幕」也可直接触发。每屏最多读取 24 条，以控制请求大小。点击蓝色单词仍可触发单独讲解。收起面板后继续主动提示，关闭小提示可停止该次朗读。提示保留来源题目，换题后不会把旧题提示当作新题讲解。

在面板的「个性设置」中选择温柔陪伴、活力伙伴或简洁老师，也可以自由编辑提示词。保存后下次回复生效，设置仅保存在当前浏览器；聊天记录仍只保留在本页生命周期内。

服务端默认连接 `http://localhost:11434/v1`。可参考 `.env.example` 创建 `.env` 修改配置；`.env` 已被 Git 忽略，且不会作为网页文件提供。若 Ollama 已运行，无需再次启动。

原有学习功能仍可静态打开；AI 聊天需要上述本地服务，GitHub Pages 无法运行 Python 后端。公开版 AI 入口仅展示本机功能说明，不会向不存在的聊天或录音接口发送请求。

### lion网页助手

右下角lion作为原 AI 面板入口，聊天、当前页面识别、多轮上下文、主动提示、个性和语音设置均沿用原有实现。点击身体打开或关闭聊天，点头部摸头、点脸颊戳脸，双击开心回应，拖拽移动；键盘 Enter 或齿轮菜单也能打开聊天。齿轮菜单提供招手、跳跃、摸头、惊讶、开心、鼓励、思考、休息，以及小巧到特大的五档大小、视线跟随、收起/恢复和位置重置。主角色沿用原有时序，播放 57 帧动作与 16 个注视方向，共 73 个逐帧高清重绘画面，保留眨眼、挥手、跳跃和双向跑步。高清素材位于 `assets/lion/motion-hd/`，分成 11 组、每帧约 444–627 像素；待机与注视预加载，其余动作按需加载。首次触发动作时会先等待高清素材（最多 20 秒），等待期间保留待机/注视；网络失败或超时使用原图回退，同一页面内再次播放直接复用已加载素材。站立帧自动对齐脚底，跑步和跳跃保留原轨迹；2×4 表情图继续作为菜单缩略图。动态角色采用适配屏幕密度的抗锯齿画布，高清帧直接保留新绘细节，原图回退时轻微锐化不透明区域、清理透明边缘噪点与绿幕色边；动作不再叠帧，以避免重影。画布不可用时回退原渲染方式。位置与设置保存在当前浏览器。

选择题和默写答对时庆祝、答错时鼓励，无需展开聊天面板；「学习表情反馈」开关与原有「主动学习提示」分别控制。边角散步默认关闭，开启后只在空闲时做短距离往返；聊天展开、录音、思考、朗读、拖拽或切到后台时停止。眨眼、呼吸、小幅摆动、弹跳和落地采用轻量动画；系统开启减弱动态效果时关闭连续运动，仍可手动切换神态。

角色素材复用独立桌宠项目的lion动画图集，原项目保持不变。网页交互仅在网站内运行；系统置顶、点击穿透和开机启动仍属于原 macOS 桌宠。公开 GitHub 版的 AI 仍需单独部署后端，本机访问方式不变。

### 语音对话（支持 Zen）

语音输入使用浏览器录音和本机 Whisper Base 识别，不依赖浏览器内置的语音识别服务。第一次安装运行 `sh scripts/setup_voice.sh`，下载约 148 MB 的多语言模型及项目专用依赖。之后仍用 `python3 server.py` 启动；会自动使用项目内的 `.venv-voice`，不修改系统 Python。

在 AI 面板点击「语音输入」，允许麦克风，讲话后点击「结束录音」。识别结果会填入输入框，可修改后发送；也可选择自动识别、中文或 English。每次最长 60 秒。原始录音仅在本机内存中处理，不保存到文件、不发给云端。

回复默认自动朗读，按中英文选择系统声音；可取消「自动朗读」、点击「停止朗读」，或用回复下方的「朗读」重播。收起面板会结束录音，朗读可继续；停止按钮或小提示的关闭按钮可停止播放。首次使用可能需要在 Zen 和 macOS「系统设置 → 隐私与安全性 → 麦克风」中允许访问。首次加载语音模型会稍慢，声音和识别准确度取决于系统声音及本地模型。

在 AI 面板展开「声音设置 · 音色与试听」，可分别选择本机中英文声音、试听、调整语速与句间停顿，设置自动保存在当前浏览器。仅使用本机声音；更多音色可从 macOS「辅助功能 → 阅读与朗读（或朗读内容）→ 管理声音」下载，重开 Zen 后选择。语音输入也可直接在文字框中使用 macOS 系统听写，无需点击网站录音按钮。

### 主机控制台与完整功能共享

双击 **启动 DeskTalk.command**，打开 [本机主机控制台](http://127.0.0.1:8000/host)，选择「开启共享」。访客扫描邀请二维码即可进入；临时邀请有效 15 分钟，最多兑换 10 次。二维码到期不影响已登录会话。

从仓库恢复到另一台 Mac 时，在克隆目录运行：

```sh
ollama pull qwen2.5:latest
uv python install 3.10
sh scripts/setup_voice.sh
sh scripts/setup_qwen_tts.sh
sh scripts/setup_share.sh
```

需要已安装 Ollama、Homebrew、uv 及 ffmpeg；Qwen3-TTS 配置适用于 Apple Silicon。先启动 Ollama，再双击启动文件。详见 [主机共享说明](主机共享使用说明.md) 与 [Qwen3-TTS 安装和实测](QWEN_TTS.md)。模型权重由安装脚本下载，不随 Git 仓库上传。

GitHub 仓库保存代码、词库、lion 素材、依赖清单和部署说明。`.env`、私有凭证、邀请二维码、运行日志、本机模型缓存与个人学习记录不发布。完整 AI 仍需要 Mac 开机联网并运行服务。

完整 AI 可以使用 [Tailscale Funnel 固定入口](固定网址与GitHub恢复.md)：安装 `brew install tailscale`，双击 **设置固定网址.command** 完成首次授权，再在控制台开启共享。访客无需安装 Tailscale。需要临时共享时也可安装 `brew install cloudflared`；临时地址每次重新创建都会变化。
